# iPhone / DyCheck five-scene evaluation

`eval_iphone_nvs.py` is the shared PSNR/SSIM/LPIPS implementation.
`recompute_baseline_metrics.py` uses that implementation to compare five fixed
external baseline predictions and any standardized `<scene>/pred.mp4` outputs.
It requires all five scenes (`apple`, `block`, `paper-windmill`, `spin`, `teddy`)
before reporting a method. It evaluates the first 49 frames at 288×512 after
the benchmark's 16:9 GT center crop. Masked scores use valid × covisible.
It records exact prediction paths and per-scene scores in each output JSON.

```bash
python eval/iphone/recompute_baseline_metrics.py \
  --gt-root /data/iphone_nvs/gt \
  --fixed-root /data/iphone_nvs/external_predictions_fixed \
  --standardized-root vidar=/data/iphone_nvs/vidar \
  --standardized-root holo4d_4rc=/data/iphone_nvs/holo4d_4rc \
  --output-root /data/iphone_nvs/recomputed_metrics
```

exact script (five scenes per method). These are
aggregate means over scenes, not best-scene scores.

all six metrics for each of the 35 evaluated scene/method pairs, including

Input MP4s were recovered from the result-only
`baseline_results_bundle_20260821.tar.zst` archive, not generated by the
public repository. The archive lacks the five EX-4D prediction MP4s, so no
fresh EX-4D score is claimed in this historical September 27 table. Later EX-4D
recovery is a separate record; do not label it as this table's rescore.
Both Holo4D AB12 step-19500 rows above are complete five-scene runs at 384×672.
No raw iPhone data, baseline weights, or prediction videos are
committed to this code repository. The Holo4D rows were sampled on one H200
(5/5 scenes per arm, 49 frames, 384×672 model canvas, 50 steps, CFG 5,
seed 42), then scored on the same benchmark-native 288×512 canvas. Their
source-conditioned backends differ from each other; the external methods
retain their original native inputs.

Compared with the archive's historical JSON, the fresh GEN3C SSIM/mSSIM are
0.311540/0.468879 rather than 0.306969/0.465778. Its PSNR/mPSNR and
LPIPS/mLPIPS agree at full reported precision; the other fixed baselines
agree at displayed precision. This isolated SSIM numerical difference has
not been attributed to a specific library or GPU backend version.
